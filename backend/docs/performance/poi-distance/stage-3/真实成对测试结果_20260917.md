## 契约评审

`python -m tools.matrix_contract --input paired-live-20260917.json --label paired-live --output paired-live-20260917-review.json`

- `label=paired-live`、`gateEligible=true`、`verdict=**incompatible**`。
- 3 match / 2 mismatch / 0 matrixUnknown / 0 routeDivergences；容差为距离 50m 或 5%、时长 30s 或 10%。
- 距离全部在容差内；**时长系统性偏短**：od-1（-62s）、od-3（-61s）超出容差被判 mismatch；od-2 因单点时长较长（710s，容差 71s）而落在容差内。
- od-1 距离 +10m 但时长 -62s，疑似矩阵与单点选了不同路径；当前 `routeDivergence` 判据（距离差 >50m 且时长差 <-30s）未能捕捉这种"近距异路"。

## 结论

- **权限不再是障碍**：新 AK 可直接调用 routematrix，剩余缺口只剩控制台 OD/秒与日额度未核验。
- 真实成对证据 **支持"矩阵不可直接替代单点"**：时长存在系统性偏差，且至少 2/5 例超容差、疑似选路不一致，合入结论维持 **NO**。
- 若要继续，需要解释时长偏短的来源（不同路径/时间模型/快照）并补 uid 绑定用例后重新冻结计划；在此之前矩阵只能作为独立近似，不能替换现有 walking 契约。
