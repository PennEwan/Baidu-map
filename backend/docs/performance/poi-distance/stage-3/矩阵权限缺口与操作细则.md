## 2. 控制台操作细则

1. 百度地图开放平台 → 控制台 → 应用管理 → 我的应用 → 选中该 AK。
2. 在「服务管理 / 配额」确认已开通 **批量算路（routematrix）**，记录权限状态、OD/秒、日额度。
3. 回填 `backend/docs/performance/poi-distance/stage-1/console-inventory.json`：`walkingMatrix.permission`、`walkingMatrix.odPerSecond`、`walkingMatrix.daily`，并把 `verified=true`、`checkedAt=<日期>`。
4. 合并查看（零请求）：
   `python -m tools.stage_baseline --mode inventory --console-inventory docs/performance/poi-distance/stage-1/console-inventory.json`
   关注 `consoleWalkingVerified` / `consoleMatrixVerified` / `consoleCheckRequired`。
5. 不修改 `backend/.env`；AK 只留在本地 `.env`，任何产物不得含 AK、URL 或请求头（`assert_no_secrets`）。

矩阵开通后重跑成对采集：

```text
python -m tools.matrix_pair --mode plan --output <新计划>.json
python -m tools.matrix_pair --mode live --plan <冻结计划>.json --qps 3 --accept-quota \
  --output <cases>.json --collection-output <collection>.json
python -m tools.matrix_contract <cases>.json
```
