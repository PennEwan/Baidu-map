## 四、复现命令

```text
# 阶段一：清单与基线
python -m tools.stage_baseline --mode inventory --console-inventory docs/performance/poi-distance/stage-1/console-inventory.json
python -m tools.stage_baseline --mode live --n 10 --qps 3 --accept-quota --output <新文件>.json

# 新 AK QPS 试测（真实；需 --accept-quota）
python -m tools.qps_probe --mode plan --output <新文件>.json
python -m tools.qps_probe --mode live --output <新文件>.json --accept-quota --concurrency 3

# 阶段二：真实账本 → 零请求分析
python -m tools.stage_baseline --mode live --n 10 --qps 3 --accept-quota --task-id <任务> --observations-output <od>.json
python -m tools.od_cache_review --input <od>.json --output <review>.json --label <来源>

# 阶段三：真实成对（需 --accept-quota，冻结计划，qps≤3）
python -m tools.matrix_pair --mode live --plan docs/performance/poi-distance/stage-3/frozen-plan.json --qps 3 --accept-quota --output <cases>.json --collection-output <meta>.json
python -m tools.matrix_contract --input <cases>.json --output <review>.json --label paired-live

# 验证
python -m pytest tests/test_stage_ledger.py tests/test_qps_probe.py tests/test_od_cache_review.py tests/test_od_export.py tests/test_matrix_contract.py tests/test_matrix_pair.py -q
```

所有 `--output` 已存在时拒绝覆盖；真实模式必须显式 `--accept-quota`。
